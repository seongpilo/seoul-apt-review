# 서울 아파트 리뷰 지도

서울 25개 자치구 지도 위에서 **반전세 후보 단지**를 검토하는 개인용 정적 웹앱입니다.
빌드 도구 없이 정적 파일만으로 동작하며 GitHub Pages에서 바로 열립니다.

- 라이브: <https://seongpilo.github.io/seoul-apt-review/>

## 무엇을 하는 앱인가

- **기준점 A (역삼)** — 직장 A 기준점에서 각 후보까지 직선거리·권역(도보/근거리/대중교통/원거리)·추정 이동시간을 보여줍니다.
- **기준점 B (미정)** — 직장 B가 정해지면 역을 고르거나 지도를 클릭해 지정하고, 각 후보까지의 거리와 방향을 함께 봅니다.
- **자치구 경계** — 서울 25개 자치구 경계·이름을 레포에 포함한 GeoJSON으로 그립니다(외부 API 의존 없음). 자치구를 클릭하면 그 구로 필터됩니다.
- **권역 색상** — 도심권·동북권·서북권·서남권·동남권 5개 권역으로 색을 나눠 봅니다.
- **후보 보드** — 상태(후보/임장예정/보류/탈락), 자치구, 최대 보증금, 최대 월세, 검색으로 거르고 지도 핀과 연동합니다.
- **상세 패널** — 단지 정보, 기준점 거리, 체크리스트(주차/컨디션/채광/인프라), 리뷰 메모, 카카오맵·네이버부동산 링크.
- **월 주거비 계산기** — 같은 자기자본으로 `전세 + 대출 이자`와 `반전세 + 월세`의 월 고정비를 비교하고, 전세→반전세 실질 전환금리와 2년 누적 차이를 계산합니다.
- **리뷰 편집 → JSON 내보내기** — 화면에서 상태·가격·체크리스트·메모를 바꾸거나 새 후보를 추가한 뒤 JSON으로 복사/다운로드해 `data/apartments.json`에 반영합니다.

## 사용 흐름

1. 상단 **리뷰 편집**을 켜면 상세 패널의 값과 메모를 직접 고칠 수 있고, 지도 왼쪽 아래에 **+ 새 후보 추가**가 나타납니다.
2. 바꾼 내용은 이 브라우저(localStorage)에 자동 저장됩니다. 상단 **JSON 내보내기**를 누르면 저장되지 않은 편집 표시(노란 점)가 있는 상태의 최신 데이터가 나옵니다.
3. **복사** 또는 **파일 다운로드** 후 GitHub에서 `data/apartments.json`을 열어 통째로 바꾸고 커밋하면 사이트 기본 데이터가 갱신됩니다.
   (모달의 **GitHub에서 편집** 링크가 해당 파일 편집 화면으로 바로 갑니다.)
4. 다른 기기에서 이어서 보려면 **불러오기**에 그 JSON을 붙여넣으면 됩니다. **기본 데이터로 되돌리기**로 초기화할 수 있습니다.

## 파일 구조

```
index.html                 화면 골격 (Leaflet CDN, Pretendard CDN)
assets/style.css           스타일 (모바일·데스크톱 반응형)
assets/app.js              지도·필터·상세·계산기·편집/내보내기 로직
data/seoul_districts.geojson  서울 25개 자치구 경계 (KOSTAT 2013 단순화, southkorea/seoul-maps)
data/apartments.json       후보 단지 데이터 (메타 + 배열)
```

## 데이터 형식

```json
{
  "meta": { "updated": "2026-11-20", "baseA": { "name": "역삼 기준점", "lat": 37.5007, "lng": 127.0365 }, "note": "…" },
  "apartments": [
    {
      "id": "seoulforest-trimage",
      "name": "서울숲트리마제",
      "district": "성동구",
      "dong": "성수동1가",
      "address": "서울 성동구 왕십리로 16",
      "lat": 37.53883, "lng": 127.04504,
      "station": { "name": "서울숲역", "lines": "수인분당", "walkM": 537, "walkMin": 6 },
      "built": "2017.05", "households": 688, "buildings": 4, "floorMax": 47,
      "parking": { "total": null, "perHousehold": null },
      "size": { "label": "전용 84㎡ (34평형)", "example": true },
      "price": { "jeonseEok": 11.0, "depositEok": 5.0, "rentManwon": 260, "maintenanceManwon": 25, "example": true },
      "status": "후보",
      "checklist": { "parking": null, "condition": null, "daylight": null, "infra": null },
      "memo": "…",
      "tags": ["서울숲"]
    }
  ]
}
```

- `checklist` 값은 `true`(좋음) / `false`(아쉬움) / `null`(미확인) 세 가지입니다.
- `price.example`이 `true`면 화면에 **검토용 예시**로 표시됩니다. 실제 조건을 확인했으면 `false`로 바꾸세요.
- `meta.baseA`를 바꾸면 기준점 A가 이동합니다.

## 데이터 신뢰도

| 항목 | 출처·성격 |
| --- | --- |
| 단지명·주소·좌표 | OpenStreetMap 실측 좌표 |
| 준공·세대수·동수·주차·역 거리 | 국토교통부 공동주택 공개 정보 및 공개 단지 정보 |
| 전세가·보증금·월세·평형 | **검토용 예시** (실거래·호가 아님) |

시세는 반드시 현장·중개사·실거래가로 확인하고 갱신하세요.

## 개인정보

이 레포는 공개 저장소입니다. 실명·전화번호·상세 주소·예식일 등 민감한 개인정보는 넣지 않습니다.
기준점은 `역삼 기준점`, `직장 B (미정)`처럼 중립적으로만 표기합니다.

## 배포

`main` 브랜치 루트(`/`)를 GitHub Pages 소스로 사용합니다. `.nojekyll`이 있어 Jekyll 처리를 거치지 않습니다.

- 배경 타일: **Esri Light Gray Canvas**(무키) — 실패 시 OSM 타일로 자동 전환하고 회색 필터를 입힙니다.
- 지도 라이브러리: Leaflet 1.9.4 (unpkg CDN), 글꼴: Pretendard (jsDelivr CDN).
- 자치구 경계는 레포 안의 GeoJSON이라 네트워크가 막혀도 경계·핀은 그려집니다.
